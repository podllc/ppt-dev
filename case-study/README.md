## Key Concepts Across All Content

### Three-Project Progression (Project-Based Airlift)
1. **We build it** - POD does the work, client observes
2. **We build it with you** - Collaborative, knowledge transfer
3. **You build it with our support** - Client leads, POD guides

### Progressive AI Adoption (AI Transformation)
1. **Level 1**: Host machine development (basic AI tools)
2. **Level 2**: Single DevContainer (service-specific AI context)
3. **Level 3**: Multi-service orchestration (cross-service AI understanding)
4. **Level 4**: Full agentic development (AI throughout CI/CD)

### POD Tone Characteristics
- Confident but approachable
- Conversational, not corporate
- First-person plural ("we", "our")
- Short, punchy statements
- Pragmatic ("We're pragmatic, not dogmatic")
- No vendor dependency messaging

## Content Standards

✅ **Include:**
- Three-project progression for all Airlift content
- Validated metrics (time savings, accuracy, coverage)
- Tech stack: Azure/AWS, .NET Core/Python, Angular/React
- POD conversational tone

❌ **Avoid:**
- Unvalidated financial claims (no $ amounts)
- Specific unproven outcomes (e.g., "50% denial reduction" → use "improved approval rates")
- Corporate jargon
- GCP references (we don't use it)
